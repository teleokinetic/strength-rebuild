A re-test is not a separate session — it's the block's final (lighter) week wearing a different face. Accessory volume drops as usual; each anchor's normal sets are replaced by a warm-up and one top set at the ×5 @ RIR 1–2 convention. The set you'd log anyway is the test — the chip captures it, the board reads it.

  • Zero new logging machinery: rows flip to "beat ___" during the week and light brass (▲) when a logged chip weight beats the mark.
  • Non-barbell marks test naturally where they live: chins max strict set on Day B, Nordic 5 slow negatives judged R vs L, carry the full distance with posture as the gate.
  • Decisions are written on the board, not remembered: gates check at week's end; stalled-twice rule triggers the pivot conversation.
  • "Judge R vs L" is subjective — fine for you; it just can't auto-flip, so Nordic gets a tap-to-confirm.

Shared mechanics, either way: tap the whole header to toggle · caret flips brass like the weight chips · state persists in localStorage (remembers how you left it) · "later phase" rows stay dimmed until their gate condition is met, then light up · the gates line ships only if you approve those trigger numbers.
