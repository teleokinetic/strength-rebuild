The contract: reps behave exactly like the working weight. One number per exercise per session — "what did your work sets hit today" — prefilled from last time, captured at finish, in the export, matched by movement name. If nothing changed, you touch nothing.

  • Per-slot flag (reps: true): only slots where reps are the progression show it — row and chins to start. Back squat stays weight-only (bottom card, unchanged).
  • Chip reads as the set you'd say out loud: "55 ×5". The ×N sits dim next to the weight; brass when the editor's open.
  • Editor grows one row — same steppers, ±1. Small "lb / reps" tags keep the two rows unmistakable.
  • Chins get honest auto-tracking: the board's "chins 5 / 12" snapshot becomes live data, and the +40 lb gate keeps using the same chip's weight side later.
